🕵️ FB OSINT Companion

Tampermonkey userscript for authorized penetration testing OSINT on Facebook.

📦 Install Userscript

Requires Tampermonkey installed first.

Features

👤 Profile scraping
🔑 Auto keyword extraction
🎯 OSINT pivot links
🤝 Mutual friends + popup scrape
👥 Group member batch scan
📰 Timeline post extraction
📸 Photo date/location scan
📞 Contact info detection
📅 Event extraction
🔗 Network collection (PYMK + groups)
⚠️ Profile change tracking
💬 Messenger notepad + templates

Installation

  1. Install Tampermonkey for your browser
  2. Click Install Userscript above
  3. Tampermonkey will prompt — click Install

Usage

Visit any Facebook profile page — the panel auto-opens. Use Ctrl+Shift+P to toggle, Ctrl+Shift+N for Messenger notepad.

Disclaimer

This tool is for authorized security testing only. All data is stored locally in your browser.
